# Shruti Mittal — Professional Portfolio

A responsive static portfolio website built from the supplied CV.

## Files
- `index.html` — main portfolio page
- `styles.css` — responsive corporate/banking design
- `script.js` — navigation and subtle reveal animations
- `ShrutiMittal_CV.pdf` — supplied CV for download
- `assets/shruti-mittal.jpg` — supplied profile photo

## Run locally
Open `index.html` in a modern browser. No build step is required.

## Publish
Upload the entire folder to any static hosting provider. Keep the folder structure intact so the CV download and profile image continue to work.

## Privacy note
The public portfolio intentionally does not display date of birth, nationality, or marital status from the CV because those details are not necessary for a professional portfolio.
